# Odoo Construction

Odoo 19 Community in Docker (`docker compose up -d`), http://localhost:8069, database `construction`.

- Custom addons: `addons/` (mounted at /mnt/extra-addons). After changing Python, `docker compose restart odoo`; for views/data, upgrade with `docker compose exec odoo odoo -d construction -u <module> --stop-after-init`.
- Config: `config/odoo.conf`.
- Run module install/tests (a second Odoo process, so use another port and pass the DB settings from the container env):
  `docker compose exec -T odoo sh -c 'odoo -d construction --db_host "$HOST" --db_user "$USER" --db_password "$PASSWORD" -u <module> --test-tags /<module> --stop-after-init --http-port=8070'`
  (prefix with `MSYS_NO_PATHCONV=1` in Git Bash).
- Secrets live in `.env` and `config/odoo.conf` (both gitignored; see the `.example` files). Backups: `bash scripts/backup.sh`.
- Backups run daily at 13:00 via Windows Task Scheduler task `OdooConstructionBackup` (log: `backups/backup.log`; Docker Desktop must be running). Restore was tested: `createdb` a new DB, then `docker compose exec -T db sh -c 'pg_restore -U "$POSTGRES_USER" -d <newdb> --no-owner' < backups/<file>.dump`; the filestore comes from `backups/filestore-<stamp>.tar.gz` (extract into /var/lib/odoo). Local-only deployment for now; HTTPS/reverse proxy is not set up.
- Addons: `construction_site` (sites linked to a project.project, budget, status workflow, chatter). `construction_boq` (bill of quantities, budget variance, quotation with markup). `construction_purchase` (POs linked to a site, subcontractor flag on partners, committed cost vs budget; installs Purchase). `construction_cost` (site on vendor bills, actual cost, Cost Overview list). `construction_progress` (percent complete per BoQ line, cost-weighted site progress, earned value, cost variance). Run ALL tests with `bash scripts/test_all.sh` (upgrades every construction_* addon, runs every test, resets the site counter). `sign_oca` (third-party OCA e-signature, see THIRD_PARTY.md) plus `construction_sign` (site on signature requests, Send for Signature button, Signatures smart button). `construction_report` (printable Site Cost Report PDF, Print menu on a site). Cost Overview has list, graph and pivot views; committed/actual/remaining cost fields are stored so they can be charted. (test_all.sh also resets the site sequence that tests consume.) Roles (construction_site/security): Viewer (read), Site Manager (create/edit), Administrator (delete); Project users/managers and system admins get them automatically; project_id is visible only to Project users. `construction_labor` (labor hours and cost from timesheets per site, total cost = bills + labor, in Cost Overview and PDF report). `construction_log` (daily site diary: weather, workers, work done, issues, safety incidents, photos; one log per site per day; Daily Logs button on site). `construction_theme` (brand colour #c2410c via one SCSS variable in static/src/scss/primary_variables.scss, app icon). `construction_equipment` (equipment register, site assignments with daily rate x days, no double-booking, equipment_cost). `construction_expense` (hr.expense linked to a site; approved/posted/paid expenses count as expense_cost; installs hr_expense). `construction_report_log` (latest 10 daily logs and incidents in the PDF, auto-installs). total_cost is built from `_total_cost_amount()`: every cost-source module extends it and must redeclare `_compute_total_cost` with the full @api.depends list (chain: labor -> equipment -> expense). Translations: French (fr) and Arabic (ar) .po files in every module i18n/ folder, generated from scripts/i18n/{fr,ar}.json by scripts/i18n_tools.py (workflow: `odoo i18n export -d construction MODULES -l fr_FR ar_001` then `python scripts/i18n_tools.py apply fr scripts/i18n/fr.json`, same for ar; `missing` lists untranslated strings). Arabic wording should be reviewed by a native speaker. Report XPath anchors must never use translatable text (use ids like section_progress). `construction_boq_template` (cost categories, reusable BoQ templates, Apply/Save as Template, BoQ Analysis pivot). `construction_billing` (numbered progress statements bill only the % completed since the last one, retention held back and released later, creates the customer invoice; needs invoicing rights). `construction_change_order` (client-approved extra work: approving adds BoQ lines and optionally raises the budget; approved orders are locked). Project is a TEST project: skip production hardening, build features. Planned next: alerts, dashboard, subcontractor contracts, then fr/ar translations for the new modules.
- Odoo 19 conventions: `<list>` not `<tree>`, `invisible=` expressions not `attrs`, `<chatter/>`, `models.Constraint`.
- API access: `python scripts/odoo_api.py <model> <method> '<json>'` (Odoo JSON-2). Needs `ODOO_API_KEY` in the environment; never write the key to a file.
- Installed apps: Sales, Invoicing, Inventory, Project, Purchase, To-do, Expenses (hr_expense), Employees (hr), Timesheets (hr_timesheet), Time Off (hr_holidays), Attendances (hr_attendance). Enterprise-only apps (Accounting, MRP II, Knowledge) are not available.
