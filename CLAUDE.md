# Odoo Construction

Odoo 19 Community in Docker (`docker compose up -d`), http://localhost:8069, database `construction`.

- Custom addons: `addons/` (mounted at /mnt/extra-addons). After changing Python, `docker compose restart odoo`; for views/data, upgrade with `docker compose exec odoo odoo -d construction -u <module> --stop-after-init`.
- Config: `config/odoo.conf`.
- Run module install/tests (a second Odoo process, so use another port and pass the DB settings from the container env):
  `docker compose exec -T odoo sh -c 'odoo -d construction --db_host "$HOST" --db_user "$USER" --db_password "$PASSWORD" -u <module> --test-tags /<module> --stop-after-init --http-port=8070'`
  (prefix with `MSYS_NO_PATHCONV=1` in Git Bash).
- Secrets live in `.env` and `config/odoo.conf` (both gitignored; see the `.example` files). Backups: `bash scripts/backup.sh`.
- Backups run daily at 13:00 via Windows Task Scheduler task `OdooConstructionBackup` (log: `backups/backup.log`; Docker Desktop must be running). Restore was tested: `createdb` a new DB, then `docker compose exec -T db sh -c 'pg_restore -U "$POSTGRES_USER" -d <newdb> --no-owner' < backups/<file>.dump`; the filestore comes from `backups/filestore-<stamp>.tar.gz` (extract into /var/lib/odoo). Local-only deployment for now; HTTPS/reverse proxy is not set up.
- Addons: `construction_site` (sites linked to a project.project, budget, status workflow, chatter). `construction_boq` (bill of quantities, budget variance, quotation with markup). `construction_purchase` (POs linked to a site, subcontractor flag on partners, committed cost vs budget; installs Purchase). `construction_cost` (site on vendor bills, actual cost, Cost Overview list). `construction_progress` (percent complete per BoQ line, cost-weighted site progress, earned value, cost variance). Run all tests with --test-tags /construction_site,/construction_boq,/construction_purchase,/construction_cost,/construction_progress. `sign_oca` (third-party OCA e-signature, see THIRD_PARTY.md) plus `construction_sign` (site on signature requests, Send for Signature button, Signatures smart button). `construction_report` (printable Site Cost Report PDF, Print menu on a site). Add /construction_sign,/construction_report to the test tags (51 tests total; add /construction_labor,/construction_log). Cost Overview has list, graph and pivot views; committed/actual/remaining cost fields are stored so they can be charted. Tests consume site sequence numbers: after running them, reset ir.sequence code construction.site number_next. Roles (construction_site/security): Viewer (read), Site Manager (create/edit), Administrator (delete); Project users/managers and system admins get them automatically; project_id is visible only to Project users. `construction_labor` (labor hours and cost from timesheets per site, total cost = bills + labor, in Cost Overview and PDF report). `construction_log` (daily site diary: weather, workers, work done, issues, safety incidents, photos; one log per site per day; Daily Logs button on site). Planned next: browser UI review by the user.
- Odoo 19 conventions: `<list>` not `<tree>`, `invisible=` expressions not `attrs`, `<chatter/>`, `models.Constraint`.
- API access: `python scripts/odoo_api.py <model> <method> '<json>'` (Odoo JSON-2). Needs `ODOO_API_KEY` in the environment; never write the key to a file.
- Installed apps: Sales, Invoicing, Inventory, Project, Purchase, To-do, Employees (hr), Timesheets (hr_timesheet), Time Off (hr_holidays), Attendances (hr_attendance). Enterprise-only apps (Accounting, MRP II, Knowledge) are not available.
